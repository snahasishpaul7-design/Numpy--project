# 🧮 NumPy Interactive Array Operations
A beginner-friendly Python project using NumPy that lets users create two 2D arrays dynamically and perform arithmetic operations on them.

---

## 🚀 Features
- Take dynamic input for rows and columns
- Create two separate 2D arrays from user input
- Convert Python lists into NumPy arrays
- Perform 7 arithmetic operations between arrays:
  - ➕ Addition
  - ➖ Subtraction
  - ✖️ Multiplication
  - ➗ Division
  - 🔢 Modulus
  - 🔋 Exponentiation
  - 🔽 Floor Division
- Display formatted NumPy array output

---

## 🛠️ Technologies Used
- Python 🐍
- NumPy 📊

---

## 📥 Installation
Make sure Python is installed on your system.
Then install NumPy:
```bash
pip install numpy
```

---

## ▶️ How to Run
```bash
python secondnumpyproject.py
```

---

## 📌 How It Works
1. Enter the number of **rows** and **columns**
2. Input values for **First Array**
3. Input values for **Second Array**
4. Choose an **operation** from the menu
5. See the result instantly!
