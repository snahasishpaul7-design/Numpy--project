# 🧮 NumPy Interactive Array Project

A simple Python project using NumPy that allows users to create and input values into two-dimensional arrays dynamically. This project helps beginners understand array creation, nested loops, and NumPy conversion.

---

## 🚀 Features

- Take dynamic input for rows and columns
- Create 2D arrays using user input
- Build two separate arrays
- Convert Python lists into NumPy arrays
- Display formatted output using NumPy

---

## 🛠️ Technologies Used

- Python 🐍
- NumPy 📊
